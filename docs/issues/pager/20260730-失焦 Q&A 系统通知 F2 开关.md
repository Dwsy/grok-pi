# Issue: 失焦 Q&A 系统通知 F2 开关

## Goal

当 grok-pi 的原生 Q&A 在失焦时抵达，发送原生桌面通知；用户可通过 F2 即时关闭或开启，默认开启。

## 验收标准 (Acceptance Criteria)

- [x] Pager 失焦且 Q&A 通知开关开启时，`ask_user_question` 发送桌面通知。
- [x] Pager 聚焦时不发送通知；开关关闭时也不发送。
- [x] F2 的 Agent 分类显示 external-only、默认开启、无需重启的开关，并持久化 `[ui].pi_ask_user_question_notifications`。
- [x] 配置相关 crate 的 `cargo check`、发布说明提取与 diff 审查通过；Pager/lib 与 binary 检查的既有阻塞已记录。

## 关键决策

| 决策 | 理由 |
|------|------|
| Pager 决定并发送通知 | 焦点状态属于 Pager；adapter 继续 headless。 |
| 与 Q&A 注入开关分离 | 通知为已有 Q&A 的即时 UI 偏好，不改变工具或扩展加载。 |
| 默认开启、无需重启 | 不影响会话协议或 Pi tool catalog，现有 `current_ui` 可立即生效。 |
